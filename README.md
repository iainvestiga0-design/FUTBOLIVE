# FUTBOLIVE — primera entrega del proyecto

## Contenido del paquete
- `index.html`: página web inicial.
- `styles.css`: estilos y diseño adaptable.
- `app.js`: interacciones del prototipo.
- `assets/logo-futbolive.png`: propuesta gráfica del logotipo.
- `assets/referencia-diseno-01.png` y `assets/referencia-diseno-02.png`: referencias visuales de diseño.

## Cómo abrir la página
1. Descomprime `FUTBOLIVE-proyecto-inicial.zip`.
2. Abre la carpeta `FUTBOLIVE`.
3. Haz doble clic en `index.html` para abrirlo en tu navegador.

No requiere instalar Python ni ejecutar un servidor para ver este prototipo.

## Qué funciona en esta versión
- Diseño oscuro adaptable a computadora y celular.
- Navegación entre secciones.
- Filtros de partidos de demostración.
- Ventanas informativas para acceso y Premium.
- Secciones de agenda, competiciones y Premium.

## Qué es y qué no es
Este paquete contiene el código fuente de la página web (frontend). **No es todavía una API ni un backend**.
Aún no incluye cuentas reales, base de datos, pagos, suscripciones activas ni transmisiones de video.

Los partidos son ejemplos de diseño, no horarios ni eventos confirmados. No hay señales de video ni enlaces de retransmisión.

## Herramientas
El prototipo está hecho con HTML, CSS y JavaScript. Para el primer desarrollo se puede editar con Visual Studio Code y publicar una versión estática en un servicio con plan gratuito, sujeto a sus límites y condiciones.
